Drop meme images here (.png / .jpg / .jpeg).

On each print, the receipt embeds ONE random image from this folder, scaled to
the receipt width and dithered to thermal black-and-white halftone. If this
folder is empty, the receipt prints without a meme.

Tips for good thermal output:
- High-contrast images dither best. Busy/dark photos can turn muddy.
- Bold meme captions (Impact text) read great.
- Roughly 4:3 or square images fit nicely; very tall images make long receipts.
